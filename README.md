# Simple Interest Calculator

## About
This project is a command-line Simple Interest Calculator written in Bash. It asks the user for a principal amount, a rate of interest and a time period, then calculates and displays the simple interest. It was created as part of the IBM Git and GitHub course final project.

## Features
- Interactive prompts for principal, rate of interest and time period.
- Instant calculation of simple interest.
- Lightweight: a single Bash script with no extra dependencies except `bc`.

## Technologies Used
- **Bash**: for the script and user input handling.
- **bc**: for decimal arithmetic.
- **Git and GitHub**: for version control, branching and collaboration.

## How to Use
1. Clone the repository:

       git clone https://github.com/<your-username>/<your-repo>.git
       cd <your-repo>

2. Run the script:

       bash simple-interest.sh

3. Enter the values when prompted:
   - Principal amount
   - Rate of interest (% per year)
   - Time period (years)

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Example
    Enter principal amount: 5000
    Enter rate of interest (% per year): 5
    Enter time period (years): 2
    Simple Interest = 500.00
